# Історична оцінка достатності часу

Для кожної області, робочого вікна та горизонту 1–7 використовуємо 20 прогнозів калібрувального періоду 11.05–27.09.2026. Моделі залишаються зафіксованими до 11.05.2026; вибір моделі й фінальні результати не змінено. Експорт відтворюється через `PYTHONPATH=src .venv/bin/python scripts/add_booking_evidence.py`.

Для поточного прогнозу P та історичної помилки e = actual − point обчислюємо сценарій тривог A = clip(P + e, 0, довжина робочого дня). Випадок зараховується як достатній, коли A + уже зайнято + резерв + запит ≤ довжина робочого дня. Частка таких випадків показана поруч із конкретним днем і оновлюється при зміні запиту або інших контролів. Це емпірична оцінка перенесення історичних помилок, не підтверджена умовна ймовірність майбутнього дня.

Поруч показуємо кількість успіхів із 20 та Wilson 95% інтервал для частки. Наприклад, 20/20 дає 100% у вибірці, але інтервал приблизно 84–100%. Інтервал має номінальне статистичне трактування за припущення незалежних біноміальних спостережень; часовий ряд війни може порушувати це припущення. Він не доводить надійність прогнозу чи безпеку.

Відсоток стосується саме запитаного бронювання. Додатковий часовий резерв у сусідній колонці й далі розраховується з номінальної верхньої денної або спільної тижневої межі. Тому історична частка може бути високою навіть коли запит перевищує цей суворіший резерв. Денна частка не є спільною ймовірністю на тиждень. Сума часу не виключає перетину івенту з тривогою та не оцінює місткість для людей. Провал покриття на фінальному holdout залишається видимим на дашборді.
